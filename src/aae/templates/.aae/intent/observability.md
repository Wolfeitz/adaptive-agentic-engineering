# AAE Observability

<!-- Describe desired reporting for model/provider usage, token provenance, cache use, latency, retries, local compute, cost, workflow phases, task outcomes, context hygiene, and privacy. Prompt or code payload capture should be opt-in and governed. -->

Collect metadata sufficient to explain model and skill routing and resource use without recording prompt, code, secret, or sensitive-data content by default. Include requested capabilities, considered and selected registry IDs and versions, selection reason, context and execution cost, outcome evidence, and fallback. Lifecycle telemetry may support promotion or deprecation proposals but cannot authorize them.
