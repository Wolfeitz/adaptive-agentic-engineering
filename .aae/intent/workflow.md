# Workflow

Develop AAE using its own requirements, design, and executable-task practices. Preserve user files, test deterministic behavior, and clearly distinguish implemented capability from roadmap intent.

**Progress telemetry:** on

When enabled for bounded long-running work, keep substantive progress updates compact and report real plan or runtime state: phase, completed/total comparable units when meaningful, current activity, remaining work, next milestone, and blockers. Prefer measurable counts over estimated percentages; do not derive completion from elapsed time or uneven checklist items. A matching `workflow.local.md` may turn this off or specialize its presentation locally.
