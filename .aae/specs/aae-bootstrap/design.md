# AAE Bootstrap Design

The reference implementation is a dependency-free Python package with an `aae` CLI. Templates are packaged as resources and installed conservatively. The deterministic compiler stage produces hashes, overlay relationships, and a semantic compiler request. Active AI runtimes use thin repository adapters to interpret the packet. This preserves portability while leaving direct provider integration open for later phases.

Testing behavior is expressed as open-world intent rather than hard-coded CLI policy. A seeded `testing.md` enables automated test creation, regression testing, coverage reporting, and risk-triggered resource-lifecycle verification while defining no arbitrary coverage threshold. A matching ignored local overlay may specialize or disable these preferences. Completion contracts continue to require verification evidence regardless of the selected testing policy.

The capability and skill fabric uses dependency-free JSON advertisements and separate Markdown procedures. A native project source is implicit; configured `aae-json`, `skill-md`, and `registry-json` adapters normalize enterprise, runtime, and local sources. Source scope records origin but does not confer trust. Owner, provenance, approval, integrity, and policy independently control authority.

Compilation writes a registry containing portable skill/registry identities and separate local runtime provenance, never procedure content. The control path is `CapabilityDemand -> CandidateSet -> SelectionDecision -> InvocationPlan -> policy gate -> procedure load -> InvocationRecord`. Demand derivation records evidence provenance. Selection grants no authority. The plan binds exact registry, skill, and procedure digests to isolation, model, tool, network, platform, data, side-effect, approval, and policy constraints. The loader rejects missing, denied, stale, or tampered plans. Invocation and outcome records provide the durable join for evaluation without self-authorizing learning.

Versioned JSON Schemas formalize the v1 contracts. Runtime validation remains dependency-free and fails closed on unknown versions. Skill telemetry uses atomic per-event files for concurrent writers. This contract leaves semantic and graph retrieval replaceable without coupling AAE to a provider.
